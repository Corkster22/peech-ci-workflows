# peech-ci-workflows

Callable GitHub Actions workflows, and the scripts they run, shared by peech-pmo-automation, peech-skills and peech-org-skills. Callers invoke them with workflow_call and pass their own credentials as secrets. No secret is stored here.

The route, and why this repository is public, are recorded in PeechTech-Framework-SharedAutomationRouting in peech-pmo-automation.
